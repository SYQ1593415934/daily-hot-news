# 今日热闻

汇集微博、抖音、知乎与 B 站热点的中文网站，提供综合榜单、热点详情、昨日总榜、每日简报和 Agent 接入说明。

## 来源与致谢

本项目的产品构想参考了 [数字生命卡兹克的 AIHOT](https://github.com/KKKKhazix/AIHOT)，感谢原作者开源分享。当前项目使用 Vinext、Cloudflare Workers 和 D1 实现；现有记录尚不足以确认代码是从 AIHOT 仓库直接派生，故不将其描述为官方版本或直接分支。AIHOT 名称与标志归其权利人所有，本项目使用独立名称。

## 功能与已知限制

- 四平台热榜、搜索、按排名与跨平台覆盖估算的综合榜；事件归并可能误合并或漏合并。
- 已核对事件的摘要及来源；未整理的条目显示原平台链接，摘要覆盖不保证完整。
- 昨日总榜依赖前一日实际采集的榜单快照；历史数据不足时无法还原完整全天总榜。
- 每日简报和 Agent 接入；更新频率、授权及数据可用性取决于部署配置和外部平台。
- 数据源可能限制访问、变更或失效；热度分数不是各平台的官方阅读量。

## 技术与运行

项目使用 Node.js 22.13+、Vinext、React、Cloudflare Workers 和 D1。安装依赖后运行 `npm run dev` 启动本地开发，`npm run build` 构建。数据库结构见 `drizzle/`；本地 D1 需按顺序执行迁移。此代码基于 Sites 模板构建，现有托管配置需要各自部署环境和数据库绑定；不能直接使用本仓库假定接入原站的数据或授权。`scripts/vite/sites-vite-plugin.LICENSE` 和 `vendor/` 中保留各自的第三方许可。

## 安全与授权

站点 MCP 接口含采集和写入工具。原部署依赖托管平台管理身份与访问；独立部署前必须实现并验证访问控制，切勿直接公开未经保护的写入接口。不要将密钥、用户数据或线上数据库上传到公开仓库。
