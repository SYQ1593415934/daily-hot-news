# 今日热闻

## 接入

站点： https://news.smoothcockatoo2.chatgpt.site/
MCP 服务器： https://news.smoothcockatoo2.chatgpt.site/mcp

优先使用当前环境中已连接的「今日热闻」MCP 工具。其他支持 MCP 的 Agent 可以在其客户端添加上述服务器，并按照客户端提示完成授权；工具是否可用、是否需要登录以及具体授权方式，以客户端和服务器实际返回为准。无法连接时报告错误，不能声称接入成功。不要收集、记录或分享用户的令牌、密码或会话信息。

## 读取和回答

- 用户要求查询时，调用可用的 `read_hotlists`；需要查看已有简报时调用 `read_reports`。根据实时结果回答，不凭记忆编造当前热点。
- 注明各平台和数据时间，披露失败、过期或缺失的平台。跨平台合并是标题匹配和已核实关联的结果，可能误合并或漏合并；不要把站内热度视为平台实际阅读量。
- 引用返回的原始链接。已有摘要和来源可作为线索；若用户要求确认事实或补充事件背景，核对可访问的一手资料或独立报道，并区分事实、争议与未核实信息。
- 默认只读取。用户明确要求刷新时才调用 `collect_hotlists`；该操作会更新站点数据。`prepare_curation` 产生的是待核对候选，不能直接视为事实。
- `save_stories` 和 `save_daily` 会修改站点数据，仅在站点所有者明确要求并且 Agent 获得相应权限时使用；不得绕过认证。无可靠来源时不编写或保存事实摘要。
- 优先使用免费公开来源；不购买服务、不调用收费接口，除非用户另行明确授权。
